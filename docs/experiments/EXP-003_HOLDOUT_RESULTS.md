## 参考（合否には使わない）

- ランダムに選んだ1,000通りのうち、766通りを上回った（上位およそ4分の1）。偶然と区別できるほどの差ではない
- この期間は、ランダムに選んでも半分強（1,000通り中525通り）が TOPIX に勝った。dev（101通り）より、この銘柄群に有利な相場だった
- 月次の超過リターンの t 値は0.72。TOPIX に勝った月は56.2%
- 超過の大半は2026年（+32.5% と +21.1%）で、2024年は TOPIX とほぼ同じだった
- 最大ドローダウンは TOPIX とほぼ同じ（−23.5% と −24.0%）

## 解釈

- 事前に固定した基準では合格で、dev（7年）と holdout（2年8か月）の両方で、コストを引いた後に TOPIX の買い持ちを上回った
- ただし、どちらの期間も統計的に強い証拠ではない（dev の t 値1.69、holdout の t 値0.72、holdout ではランダムの上位4分の1程度）。
  「上回る傾向がある」までは言えるが、「確実に勝てる」とは言えない
- 設計者（Claude）が 2024〜2026年の相場の大まかな動きを一般知識として知っていた可能性があり、holdout の結果はその分を割り引いて読む必要がある
  （`EXP-003_HOLDOUT_DEVIATION.md` を参照）
- 次の段階は、事前に決めたルールでの少額の前向き検証（実運用）である。holdout は使い終えたので、これ以降の判断は前向きの成績だけで行う
