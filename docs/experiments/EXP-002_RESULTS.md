## 分かったこと

- **会社予想の上方修正・予想超過（E1）の後、20営業日で TOPIX を上回るリターンはなかった。**
  超過リターンの平均は +0.005%（中央値 −0.88%）。上方修正（496件、+0.11%）でも本決算の予想超過（474件、−0.10%）でも、ほぼゼロだった。
- **決算発表でプラスに反応した銘柄（E2）は、その後の超過リターンの平均が +0.39% だった。** ただし月次の t 値は −0.55 で、
  エントリー月を等しく扱うとマイナスになる。同じ月の決算イベントを無作為に選んだ場合（95%点 +266,317）と区別できない。
- 悪いニュースの側（下方修正・予想未達 −1.16%、反応がマイナス −0.66%）は、良いニュースの側より成績が悪かった。
  向きは決算後のドリフトと矛盾しない。ただし、どれも t 値の絶対値は2未満で、ロングだけの売買では利益にならない。
- 売買の頻度を上げると悪化した（保有5日は E1・E2 とも損失）。60日保有は20日より良いが、有意ではない。
- イベントが決算期に集中するため、決算期の間はポジションが1〜2銘柄だけの日が多い（E1 では保有がある日の4分の1以上が2銘柄以下）。
  そのため最大ドローダウン（基本コスト）が −44%〜−56% と大きく、どちらの候補も買い持ち（B0・B1）に負けた。

## 事前登録にない補足の計算（判定には使わない）

結果を見た後に、確認のため次を計算した。判定には使っていない。

- 取引単位の超過リターンの t 値（月でまとめない単純な t 値）：E1 0.02、E2 1.52。この計算でも2に届かない
- データの異常の確認：1日で30%を超えて動いた日はなかった。E1 の1回あたりのリターンは −44%〜+55% の範囲で、最も悪い取引は2020年2〜3月の急落の時期のもの

## 注意

- 現在上場している銘柄だけ・分割調整済みの日足・配当なしの結果であり、将来の成績の予測ではない
- 流動性の条件（1億円）を満たすのは306銘柄中218銘柄（dev）で、小型株のドリフトは対象外になっている
- 等金額・端数株・同時保有数の上限なしで評価している。実際には単元未満株（S株など）が必要
- API の動作確認で、V4 に含まれない 9997 の 2024-05-14 の1日分の株価を見た（事前登録の「取得時の注意」を参照）。V13 の候補から外すかどうかは人間が判断する

## 次の判断（人間向け）

- 値動きだけの方法（EXP-001 まで）に続いて、決算イベントの2案も不合格だった
- holdout（開示日 2024-02-01..2026-08-14）は未使用のまま残っている。ただし、上の診断を見て新しい案（例: 60日保有、下方修正の銘柄を避ける）を作ると、
  それは dev の結果を見て作った案になる。検証するなら、新しい事前登録を書いてから holdout で1回だけ確かめる
- J-Quants Standard の購読料（年39,600円、30万円の13.2%）に見合う使い道は、今回は見つからなかった（レビュー P5 の判断材料）
