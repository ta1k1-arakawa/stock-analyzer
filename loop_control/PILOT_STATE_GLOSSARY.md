# Pilot state glossary

| State | Meaning |
| --- | --- |
| NEW | ループは存在するが，実行するタスクと契約がまだ登録されていない状態です． |
| PLANNED | 1つのタスクと変更不能な契約がハッシュによって登録された状態です． |
| READY | 作業場所，基準コミット，契約，予算が確認され，実装を開始できる状態です． |
| IMPLEMENTING | 登録されたタスクだけを，許可された範囲内で実装している状態です． |
| VERIFYING | 実装結果が固定済み契約を満たすか，独立した確認を行っている状態です． |
| RETRY_ALLOWED | 同じタスクに対する実装上の不具合を，許可された回数内で修正できる状態です． |
| HUMAN_GATE | 正確な対象と操作について，人間の承認記録を待って自動処理が停止している状態です． |
| ACCEPTED | 固定済み契約を満たしたことが確認され，新しいタスクを自動選択しない状態です． |
| REJECTED | 固定済み契約を満たさず，別の方法へ自動的に進めない状態です． |
| BLOCKED | 安全性，予算，環境または証拠の問題によって処理を継続できない状態です． |
| CANCELLED | 人間または契約の判断によって，完了前に処理が終了した状態です． |
| DONE | 承認された成果が保存され，ループ全体が終了した状態です． |
